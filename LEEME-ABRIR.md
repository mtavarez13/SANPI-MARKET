# Sanpi Market actualizado

Este paquete incluye el código fuente y la carpeta `dist` compilada. No está vacío: encontrará `src`, `dist`, `package.json`, `firestore.rules` y las instrucciones de contabilidad.

Para ejecutarlo localmente:

1. Extraiga todo el ZIP en una carpeta.
2. Abra una terminal en esa carpeta.
3. Ejecute `npm install` y después `npm run dev`.
4. Abra la dirección local que indique la terminal.

La carpeta `dist` es para servir la versión compilada desde un servidor web; abrir `dist/index.html` directamente con doble clic puede dejar la página en blanco. Consulte `LEEME-CONTABILIDAD.md` antes de conectar Firestore en producción.
